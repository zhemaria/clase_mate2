Bienvenida al Tema 5. En el Tema 4 se aprendió a comparar cantidades con razones y a predecirlas con proporciones. Este tema se dedica a un caso particular muy especial: las razones cuyo segundo término es siempre 100. Se llaman porcentajes y aparecen en calificaciones, descuentos, impuestos, estadísticas e intereses.

Para pensar desde ya: si en un examen de 25 preguntas se contestaron bien 18, ¿qué porcentaje es? Al final de la sección 4 se resolverá con dos métodos distintos.

1. El porcentaje como razón de 100

La palabra porcentaje viene del latín per centum, «por cada cien». Un porcentaje es una razón cuyo segundo término es siempre 100.

Idea central

25%  =  25100  =  0.25

Las tres formas representan lo mismo: 25 partes de cada 100. Solo cambia la notación.

2. Conversiones entre porcentaje, decimal y fracción

Cualquier porcentaje se puede expresar como decimal o como fracción, y viceversa.

Reglas de conversión entre las tres formas
ConversiónProcedimientoEjemplo
Porcentaje → decimalDividir entre 100: el punto decimal se mueve dos lugares a la izquierda.45% = 0.45
Decimal → porcentajeMultiplicar por 100: el punto decimal se mueve dos lugares a la derecha.0.07 = 7%
Porcentaje → fracciónEscribir como n/100 y simplificar.40% = 40/100 = 2/5
Fracción → porcentajeDividir numerador entre denominador y multiplicar por 100.3/4 = 0.75 = 75%

Más de 100% y menos de 1%: las reglas no cambian. 150% = 1.5 (una vez y media el total) y 0.5% = 0.005 (medio punto de cada cien). Un porcentaje mayor que 100% indica una cantidad mayor que el total de referencia.
Error frecuente: confundir 0.5 con 5%. Son distintos: 0.5 = 50%, mientras que 5% = 0.05. La regla de los dos lugares del punto decimal evita este error.

3. Una sola fórmula: el triángulo del porcentaje

Todo problema de porcentaje relaciona tres elementos: la parte, el todo (el total de referencia) y el porcentaje. Los tres se unen en una sola fórmula:

Parte = Porcentaje × Todo

El porcentaje se usa siempre en forma decimal dentro de la fórmula (15% → 0.15). El triángulo ayuda a recordar qué operación usar: se cubre el elemento que falta y se lee lo que queda. Lo que está lado a lado se multiplica; lo que está arriba y abajo se divide.

4. Los tres casos fundamentales

Según cuál de los tres elementos falte, hay tres casos. La pregunta clave antes de calcular es siempre: ¿qué me falta?

Caso 1 · Hallar la parte (conocidos el porcentaje y el todo)

Ejemplo 1

¿Cuánto es el 15% de $80?

1 Falta la parte. Se conocen el porcentaje (15% = 0.15) y el todo ($80).
2 Parte = 0.15 × 80 = 12.

Respuesta: $12.

Caso 2 · Hallar el todo (conocidos la parte y el porcentaje)

Ejemplo 2

El 30% de un número es 45. ¿Cuál es ese número?

1 Falta el todo. Se conocen la parte (45) y el porcentaje (30% = 0.30).
2 Todo = Parte ÷ % = 45 ÷ 0.30 = 150.

Respuesta: 150. Verificación: 0.30 × 150 = 45. ✓

Caso 3 · Hallar el porcentaje (conocidos la parte y el todo)

Ejemplo 3 · El examen del principio

Se contestaron bien 18 de 25 preguntas. ¿Qué porcentaje es?

1 Falta el porcentaje. Parte = 18, todo = 25.
2 % = 18 ÷ 25 = 0.72.
3 Se convierte a porcentaje: 0.72 × 100 = 72.

Respuesta: 72%.

¿Cuál es el todo? Es la cantidad de referencia, la que aparece después de la palabra «de»: «el 15% de $80», «18 de 25». Confundir la parte con el todo es el error más común en el caso 3.

5. Método alternativo: la proporción porcentual

Como un porcentaje es una razón de 100, cualquier problema se puede plantear como la proporción directa estudiada en la Lección 4.2:

partetodo = %100

Se colocan los tres datos conocidos, la x en el lugar del que falta, y se resuelve con el producto cruzado.

Ejemplo 4 · Los tres casos por proporción
1 Parte: 15% de 80 → x80 = 15100 → 100x = 1,200 → x = 12.
2 Todo: 45 es el 30% → 45x = 30100 → 30x = 4,500 → x = 150.
3 Porcentaje: 18 de 25 → 1825 = x100 → 25x = 1,800 → x = 72%.
¿Cuál método conviene? Los dos dan el mismo resultado. La fórmula es más rápida con calculadora; la proporción ayuda cuando no se sabe qué operación hacer, porque solo pide colocar bien los datos. Conviene dominar ambos y usar uno para comprobar el otro.
